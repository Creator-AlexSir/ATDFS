# СПСА — Система прогнозирования спроса на авиабилеты

Веб-приложение для аналитиков авиакомпании, которое помогает прогнозировать спрос на авиабилеты на основе исторических данных и рекомендовать оптимальную цену на рейсы.

## 🚀 Как запустить программу

Так как проект использует современные модули JavaScript (ES6), **нельзя** просто открыть файл `index.html` двойным кликом. Браузер заблокирует загрузку скриптов.

**Инструкция по запуску:**
1. Скачайте папку с проектом и откройте её в редакторе **VS Code**.
2. Установите расширение **Live Server** (автор Ritwick Dey), если оно ещё не установлено.
3. Нажмите правой кнопкой мыши на файл `index.html` и выберите **«Open with Live Server»**.
4. Программа автоматически откроется в вашем браузере (обычно по адресу `http://127.0.0.1:5500`).

## 🧭 Как пользоваться

Интерфейс разделен на несколько разделов (вкладок) в левом боковом меню.

### 1. Дашборд (Главная страница)
Здесь происходит основная работа с прогнозом.
* **Ввод истории:** Введите числовой ряд продаж в текстовое поле (например: `10 15 20 25 30`). Числа можно разделять пробелом, запятой или точкой с запятой. *Символ `*` можно использовать для пометки распроданных рейсов.*
* **Выбор формулы:** Выберите математическую модель (линейный тренд, полином и т.д.), по которой будет строиться прогноз.
* **Параметры:** Задайте горизонт прогноза (на сколько периодов вперед считать) и вместимость рейса.
* **Кнопка «Построить прогноз»:** Нажмете — программа рассчитает коэффициенты методом наименьших квадратов (МНК) и отрисует график.
* **График:** Фиолетовая линия — это теоретическая модель, оранжевая — расчетная (МНК).
* **Рекомендация цены:** Система автоматически предложит цену, основываясь на прогнозе спроса и вместимости.
* **Кнопки действий:** Аналитик может «Скорректировать цену» (ввести свою), а Руководитель — «Утвердить».

### 2. Роли пользователей (Смена доступа)
В левом нижнем углу сайдбара есть выпадающий список ролей. От выбранной роли зависит, какие кнопки вам доступны:
* **Аналитик** — может строить прогноз и корректировать цену.
* **Руководитель отдела продаж** — может только утверждать предложенную цену.
* **Менеджер по продажам** — доступен только просмотр (кнопки изменения цены скрыты).
* **Администратор БД** и **Специалист по безопасности** — имеют соответствующие права по настройке и аудиту.

### 3. Рейсы
Справочник доступных рейсов с указанием вместимости воздушного судна.

### 4. Отчёты
Раздел для выгрузки данных. Нажмите «Скачать отчёт», и программа сгенерирует CSV-файл с историей изменения цен, который можно открыть в Excel.

### 5. Журнал действий
Здесь фиксируются все изменения цен (кто, когда, какая цена и её статус). Данные сохраняются в памяти браузера (localStorage), поэтому при перезагрузке страницы история не пропадает.

## 🛠 Технические детали
* **Фронтенд:** HTML5, CSS3, JavaScript (ES6 Modules).
* **Библиотеки:** jQuery, Flot (для построения графиков).
* **Математическое ядро:** Метод наименьших квадратов (МНК), генерация стохастических рядов, парсинг пользовательских формул.
