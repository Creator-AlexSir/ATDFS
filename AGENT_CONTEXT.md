# Контекст проекта для ИИ-агента (СПСА)

Этот файл содержит правила и описание структуры проекта. ИИ-агент обязан прочитать его перед началом работы и строго следовать инструкциям.

## 1. О проекте
Мы разрабатываем систему прогнозирования спроса на авиабилеты (СПСА) для университетской лабораторной работы.
Стек: HTML, CSS, JavaScript (ES6 модули), jQuery, Flot (для графиков).
Запуск: только через Live Server в VS Code (иначе ES-модули не работают).

## 2. Железные правила (НЕ НАРУШАТЬ)
1. **Никаких лишних классов:** Не придумывай новые CSS-классы, обертки (div) и идентификаторы, если об этом не просят явно. Пиши код строго под существующую верстку.
2. **Модульность:** В HTML подключается ТОЛЬКО `main.js`. Все вспомогательные модули импортируются внутри main.js. В них функции пишутся с `export`.
3. **Никаких глобальных переписываний:** Не переписывай файлы целиком! Показывай только тот фрагмент кода, который меняешь, и указывай, в какой файл и на какую строку его вставить.
4. **Без воды:** Отвечай максимально кратко. Не нужно длинных лекций, просто выдай нужный код.
5. **Не трогай системные папки:** Не сканируй node_modules, .git.
6. **Не ломай математику:** В папке `MK-main` лежит рабочий код калькулятора. Мы переносим его оттуда. Не меняй логику формул и МНК без прямой просьбы.

## 3. Структура проекта
- `index.html` — разметка (сайдбар, вкладки `dashboard`, `flights` и т.д.).
- `style.css` — стили.
- `main.js` — точка входа (только импорты и запуск).
- `ui.js` — навигация по вкладкам.
- `validation.js` — проверки ввода (пока пустой).
- `math.js` — (СОЗДАДИМ) математическое ядро (расчеты МНК, парсинг формул, генерация рядов).
- `chart.js` — (СОЗДАДИМ) отрисовка графиков через Flot.
- `dashboard.js` — (СОЗДАДИМ) связка интерфейса и математики для вкладки "Дашборд".
- `jquery.js`, `jquery.flot.js` — библиотеки.
- **Папка `MK-main` (донор):** `main.js` — здесь лежит исходная математика.

## 4. Навигация
- Кнопка меню: `<button class="nav-item" data-tab="flights">Рейсы</button>`
- Блок контента: `<main class="tab-content" id="flights">...</main>`
Значение `data-tab` ВСЕГДА должно совпадать с `id`. Переключение в `ui.js` через `querySelector`.

## 5. График (Flot)
Контейнер: `<div id="plot-container">`.
Вызов: `$.plot($("#plot-container"), data, options)`.
Данные: `[[x1, y1], [x2, y2], ...]`.

## 6. Что делать, если задача сложная
Если задача требует изменений в нескольких файлах, сначала напиши короткий план (2-3 пункта). Дождись моего подтверждения, и только потом выдавай код.
